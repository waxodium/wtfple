# Contributing
Hello, there! Welcome to contributing.

## File to edit
We're (yet) to have a contributing guidelines. So we use
github standard contribution for now

**What file to edit?** 

Please Edit the *txt file at root. Those are raw files edited
in text editor. Every whitespaces and indentation there matters. 
So please leave it that way. Maintainer will fix indentation
and spacing manually. 

Every single text file here are ascii compliance. 
So if you're working with it, please note. We do not work with UTF8
files.

The finished file is [LICENSE](./LICENSE) free to use, and finished
merged from one of any stable commit.
